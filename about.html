About CSS

CSS stands for Cascading Style Sheets. It controls the visual presentation of HTML elements.

Inline CSS

Inline CSS is written directly inside an HTML element using the style attribute.

Internal CSS

Internal CSS is written inside a style element in the HTML head.

External CSS

External CSS is written in a separate style.css file.

CSS Selectors

Element selectors target HTML tags. Class selectors can style multiple elements. ID selectors identify a unique element.
